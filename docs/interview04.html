Next week, you will have the opportunity to demonstrate your mastery of the skills and concepts discussed in Unit 04: System Calls to the instructor or a teaching assistant in a 15 minute in-person coding interview.

This interview will evaluate your proficiency in the following areas:

  1. Writing a Makefile.

  2. Executing a process.

  3. Walking the file system.

  4. Testing file metadata.

More details of what you need to know about these particular areas can be found in Checklist 04.

Sample Interview¶

Here is an example of the types of tasks the interviewer may ask you to perform:

  • [ ] Download the following:

    • Makefile: https://yld.me/raw/jdtr
    • wcd.c: https://yld.me/raw/gQ16

  • [ ] Complete the Makefile and build wcd.

  • [ ] Implement the wcd_file function (using fork and execlp).

  • [ ] Implement the wc_directory function (using opendir, readdir, closedir).

  • [ ] Use make test to verify functional correctness and memory safety.

Hints¶

  • You should be familiar with using git to create a branch, record a commit, and upload changes to GitHub.

  • You should be familiar with downloading files using curl or wget.

  • You should be familiar with gdb (or any debugger).

  • You should be familiar with valgrind.

Consulting Resources¶

As with your Reading and Homework assignments, you are allowed to consult the course texts, slides, notes, the Internet, and even AI tools. However, you cannot communicate with anyone else nor can you ask an AI tool to generate a solution.

Be mindful that the interviewer is assessing your proficiency and how much you have internalized. Over reliance on any external resource will be viewed negatively in regards to your mastery of the material.
