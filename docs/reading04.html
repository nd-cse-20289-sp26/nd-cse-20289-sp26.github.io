Python 3¶

In this course, we will be using Python 3.12+ and some additional libraries such as Requests.

On the student machines, you can use the instructor's copy of Python by making the following modifications to your PATH environmental variable:

export PATH=~pbui/pub/pkgsrc/bin:$PATH

This will give you access to a more current version of Python along with some of the libraries we will be using such as Requests.

To make this persistent, you should add this to the bottom of your ~/.bashrc if you have not already.

Script: exists.py¶

Use the echo.py script as the basis for a Python script called exists.py, which accomplishes the same task as the modified version of exists.sh in Reading 02:

# Run script and check error code
$./exists.py * && echo Success
exists.py exists!
README.md exists!
Success

$ ./exists.py * ASDF || echo Success
# Run script and check error code
exists.py exists!
README.md exists!
ASDF does not exist!
Success

Hints¶

  • You will probably want to use os.path.exists to check if a file exists.

  • You will probably want to use sys.exit at the end of the script to return 0 if all files exist, otherwise return 1 any of the files does not exist.

  • You will probably want to use string formatting or f-strings when printing.
