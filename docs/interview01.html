Next week, you will have the opportunity to demonstrate your mastery of the skills and concepts discussed in Unit 01: Bourne Shell to the instructor or a teaching assistant in a 15 minute in-person coding interview.

This interview will evaluate your proficiency in the following areas:

  1. Using git

  2. Using the shell

  3. Shell Scripting

  4. Pipelines/Filters

More details of what you need to know about these particular areas can be found in Checklist 01.

Sample Interview¶

Here is an example of the types of tasks the interviewer mask ask you to perform:

  • [ ] Locate the $NETID.sh script in the ~pbui/pub/scratch/cse.20289.sp26/practice01 directory and copy it to the practice01 folder in the assignments repository.

  • [ ] Complete the $NETID.sh script such that it outputs the first three characters of each command line argument using a for loop.

  • [ ] Filter the output of running the script with the test input:

    • [ ] Output words in uppercase.
    • [ ] Count words with multiple vowels.

Hints¶

  • You should be familiar with using git to create a branch, record a commit, and upload changes to GitHub.

  • You should be familiar with downloading files using curl or wget.

  • You should be familiar with extracting tarballs.

Consulting Resources¶

As with your Reading and Homework assignments, you are allowed to consult the course texts, slides, notes, the Internet, and even AI tools. However, you cannot communicate with anyone else nor can you ask an AI tool to generate a solution.

Be mindful that the interviewer is assessing your proficiency and how much you have internalized. Over reliance on any external resource will be viewed negatively in regards to your mastery of the material.
