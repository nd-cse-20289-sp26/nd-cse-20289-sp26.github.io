Next week, you will have the opportunity to demonstrate your mastery of the skills and concepts discussed in Unit 02: Python to the instructor or a teaching assistant in a 15 minute in-person coding interview.

This interview will evaluate your proficiency in the following areas:

  1. Using Data Structures: list, dict

  2. Processing Data: requests, csv

  3. Functional Programming: map, list comprehensions, generators

  4. Parsing Arguments: sys.argv, match

  5. Testing: doctest, mypy

More details of what you need to know about these particular areas can be found in Checklist 02.

Sample Interview¶

Here is an example of the types of tasks the interviewer mask ask you to perform:

  • [ ] Download the following Python script template: https://yld.me/raw/tEny to practice02.py.

    Discussion¶

    • How would you execute this script?
    • Does the extension matter?

  • [ ] Implement the fetch_csv_data function using map and a list comprehension.

    Discussion¶

    • How would you test this code?
    • How would you print the last value?
    • How would you print the data in ascending order?
    • How would you print the median value?

  • [ ] Implement the count_grounds function using a dict.

    Discussion¶

    • How would you test this code?
    • How did you handle possible KeyErrors?
    • How could you use a while loop instead of a for loop?
    • How would you print all the key, value pairs in the dict?

  • [ ] Implement the main function.

    Discussion¶

    • How would you test this code?
    • How would you handle no arguments?
    • How would you handle invalid arguments?
    • How did you handle formatting the output?

Hints¶

  • You should be familiar with using git to create a branch, record a commit, and upload changes to GitHub.

  • You should be familiar with downloading files using curl or wget.

  • You should be familiar with generator expressions.

  • You should be familiar with sum.

  • You should be familiar running doctest and mypy.

Consulting Resources¶

As with your Reading and Homework assignments, you are allowed to consult the course texts, slides, notes, the Internet, and even AI tools. However, you cannot communicate with anyone else nor can you ask an AI tool to generate a solution.

Be mindful that the interviewer is assessing your proficiency and how much you have internalized. Over reliance on any external resource will be viewed negatively in regards to your mastery of the material.
